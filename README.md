
# ÉLORA – Fine Dining Restaurant Website

A premium, responsive restaurant website designed to showcase elegant dining, signature dishes, menu categories, and table reservations.

## 🌐 Live Website

[Visit ÉLORA Fine Dining](https://rabiyaashna.github.io/ELORA-Restaurant/)

## ✨ Features

- Elegant restaurant landing page
- Restaurant story and introduction
- Menu with food categories and prices
- Interactive menu filtering
- Responsive mobile navigation
- Table reservation form with demo confirmation
- Contact information
- Google Maps integration

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Flexbox & CSS Grid
- Google Maps Embed
